# 网页手册工坊

样式库 V1.4.7 · 设计者：吖君 · 更新日期：2026-11-20

[样式库与技能包下载](https://arjuntam.github.io/handbook-workshop/)

- 默认 MiSans，可选思源黑体、思源宋体；字体与色系、外框深浅、字号独立，项目级共用配置。
- 基础规范包含 B03 底部翻页导航；内容样式保留既有变体、分流、就地附件和章节导航组件，菜单最多两层。
- V1.4.1 补齐 L22 复选清单、L23 图标折叠卡、L24 编号折叠卡网格；L03 增加横向整栏编号图文标签，L12 增加按实际段数统计的分组折叠话术库，支持逐条复制和反馈。
- V1.4.2 内容样式按六种用途分类；总览先选类别，每类提供用途、选型说明与样例。左侧类别可折叠，仍最多两层；原编号与链接保留。
- V1.4.3 思源黑体与宋体按正文、标题、卡片、目录、表头、指标分别校准字重；MiSans 保持基准。配置导出采用独立实色按钮，文件名包含所选方案及上海导出时间，配置结构保持兼容。
- V1.4.4 新增紧凑小字预设和 80%–150% 原生字号滑块；保留日常与演示预设，可还原、实时预览并记住选择。比例随配置导出，生成、离线重建和旧页换样式共同使用；文件名包含自定义比例。
- V1.4.5 两种分发包统一命名为 Lite / Full，按钮、实际下载文件名与技能说明同步。旧版本下载保留。
- V1.4.6 清理个人电脑绝对路径；默认使用包内样例和封面素材，浏览器验收使用当前项目的 Playwright 与标准浏览器通道，支持显式环境配置。已验证只读安装、换目录构建和缺依赖报错；不自动安装浏览器。
- V1.4.7 新增默认关闭的 B04 分享卡片元信息，使用用户提供的成品截图；手册与资料中心支持页面级分享配置。已有静态网页可另存副本追加，无需重排或替换旧 runtime；SDK 增强仅预留，未接入。
- 默认下载Lite 包，约 1.51 MiB，低于本次 WorkBuddy 返回的 5 MiB 限制。Lite 包不包含大字库；构建时只下载选中的完整字体并校验大小与 SHA-256。Full 包包含三款字库和授权文件。
- 生成的手册携带所选字体，可独立离线查看和重新构建。业务手册默认只显示资料更新日期，样式库版本和设计者只出现在本库使用说明。

思源黑体和宋体来自 Adobe 官方完整 SC 变量字体，文件指纹已与官方 Git blob 核对，没有自行裁字。授权随字体保留，详见 assets/fonts/source-han-sans-LICENSE.txt 与 source-han-serif-LICENSE.txt。

已完成本机生成、离线重建、独立手册、键盘、多项勾选、独立展开、真实剪贴板和分发包检查；本次五处样式均通过三款字体、两种窗口和两档文字大小检查。实际 WorkBuddy 云端导入、外网下载及缓存持续性仍需在该环境验证。
