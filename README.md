- V1.4.7 新增默认关闭的 B04 分享卡片元信息，使用用户提供的成品截图；手册与资料中心支持页面级分享配置。已有静态网页可另存副本追加，无需重排或替换旧 runtime；SDK 增强仅预留，未接入。
- V1.4.8 B04 默认由 Agent 读取页面内容生成分享封面与方图，保存到新版 assets 并自动配置图片地址；用户无需准备图片或图床，已有指定图优先使用。保留原页面与资料日期，SDK 仍未接入。
- 默认下载 Lite 包，约 1.53 MiB，低于本次 WorkBuddy 返回的 5 MiB 限制。Lite 包不包含大字库；构建时只下载选中的完整字体并校验大小与 SHA-256。Full 包包含三款字库和授权文件。
- 生成的手册携带所选字体，可独立离线查看和重新构建。业务手册默认只显示资料更新日期，样式库版本和设计者只出现在本库使用说明。
