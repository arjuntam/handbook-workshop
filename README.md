# 网页手册工坊

样式库 V1.3.7 · 设计者：吖君 · 更新日期：2026-11-19

[样式库与技能包下载](https://arjuntam.github.io/handbook-workshop/)

默认下载网页版共享包，约 1 MiB，低于本次 WorkBuddy 网页端返回的 5 MiB 限制。保留规则、生成器、品牌素材、地图和示例源文件；完整原始 MiSans 字体在首次构建时从资源清单指定 HTTPS 地址下载，验证大小和 SHA-256 后缓存。下载或验证失败则停止，不以系统字体代替。

字体缓存不要求技能安装目录可写。生成的项目会复制完整字体到自己的资源目录，可离线打开和重新构建。新云任务环境可能需要重新下载。亦提供含全部资源的完整离线包。

已验证本机只读安装环境下的下载、缓存、错误处理、生成与离线重建。WorkBuddy 网页端的实际导入及外网访问权限仍需在用户环境验证。

业务手册默认只显示资料更新日期。样式库版本和设计者只出现在样式库自己的使用说明中。
