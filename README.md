# 网页手册工坊

样式库 V1.4.0 · 设计者：吖君 · 更新日期：2026-11-19

[样式库与技能包下载](https://arjuntam.github.io/handbook-workshop/)

- 默认 MiSans，可选思源黑体、思源宋体；字体与色系、外框深浅、字号独立，项目级共用配置。
- 基础规范新增 B03 底部翻页导航；内容样式新增四个受控变体及分流、就地附件、章节导航组件，菜单仍最多两层。
- 默认下载网页版共享包，约 1.03 MiB，低于本次 WorkBuddy 返回的 5 MiB 限制。共享包不包含大字库；构建时只下载选中的完整字体并校验大小与 SHA-256。完整离线包包含三款字库和授权文件。
- 生成的手册携带所选字体，可独立离线查看和重新构建。业务手册默认只显示资料更新日期，样式库版本和设计者只出现在本库使用说明。

思源黑体和宋体来自 Adobe 官方完整 SC 变量字体，文件指纹已与官方 Git blob 核对，没有自行裁字。授权随字体保留，详见 assets/fonts/source-han-sans-LICENSE.txt 与 source-han-serif-LICENSE.txt。

已完成本机生成、下载、键盘、字体实际加载、三字体全页面四种窗口/文字模式与分发包检查。实际 WorkBuddy 云端导入、外网下载及缓存持续性仍需在该环境验证。
